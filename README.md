# Position & Role Finder Minisoccer

Fase 1 (Lampiran C.5 PRD): onboarding → kuesioner gaya bermain → hasil posisi
& role, seluruhnya berjalan di browser dan tersimpan di IndexedDB. Tidak ada
akun/login dan tidak ada panggilan backend.

## Menjalankan proyek

```bash
npm install
npm run dev
```

Perintah lain:

- `npm run build` — type-check (`tsc -b`) lalu build produksi.
- `npm run lint` — oxlint.
- `npm run preview` — pratinjau hasil build.

Lihat `Docs/CLAUDE.md` untuk aturan kerja dan `Docs/PRD-Minisoccer-Position-Role-Finder.md` untuk spesifikasi produk.
